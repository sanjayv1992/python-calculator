\chapter{Python Code Listings}\label{app:code}

The routines below are in \texttt{research-paper/code/numtheory.py}. Their tests are in \texttt{research-paper/code/test\_numtheory.py}. Run the tests with \texttt{python -m pytest research-paper/code}.

\section{Routines}

\begin{itemize}
  \item \texttt{sieve(n)}: the primes up to $n$ (Eratosthenes).
  \item \texttt{gcd(a, b)}: the Euclidean algorithm (Theorem~\ref{thm:euclid}).
  \item \texttt{ext\_gcd(a, b)}: returns $(d,x,y)$ with $ax+by=d=\gcd(a,b)$ (Theorem~\ref{thm:bezout}).
  \item \texttt{phi(n)}: Euler's totient, by factoring out primes.
  \item \texttt{modpow(b, e, m)}: square-and-multiply modular exponentiation.
\end{itemize}
